ТЕСТОВАЯ КОПИЯ ПРОЕКТА «НОВАЯ РЕАЛЬНОСТЬ»

Подготовлена отдельная папка novaya-realnost-test. В эту копию добавлена основа CRM: тестовая база Supabase, регистрация клиентов, защищённый вход сотрудников, кабинет клиента, кабинет менеджера/администратора, серверная проверка ролей, создание и назначение менеджеров.

Рабочий Netlify-проект spiffy-kheer-42015a не подключён и не изменён.

ДАЛЬШЕ
1. Откройте `SETUP-TEST-CRM.md` и выполните настройку отдельного TEST-проекта Supabase.
2. Примените SQL из `supabase/migrations/202611090001_crm_core.sql`.
3. Скопируйте `.env.example` в `.env` и добавьте только ключи тестовой базы.
4. Запустите проект через `netlify dev`.

Не используйте production-ключи. Не отправляйте service-role/secret key в чат. Не выполняйте `netlify link`, `netlify deploy` или `netlify deploy --prod` для рабочего сайта.
