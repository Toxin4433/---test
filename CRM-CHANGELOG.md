# CRM 2.1 — что изменено в тестовой копии

## Данные и доступ
- Добавлена тестовая схема Supabase: профили клиентов/сотрудников и постоянная таблица заявок.
- Для самостоятельной регистрации доступна только роль `customer`; роли `manager` и `admin` назначаются доверенным администратором.
- Прямое чтение/изменение таблицы заказов из браузера закрыто; операции выполняются через проверяемые RPC-функции.
- Менеджер получает только заявки с `assigned_to`, равным ID его собственной учётной записи. Ограничение действует и для завершённых заявок.
- Администратор получает все заявки, назначает и переназначает ответственных, создаёт менеджеров и отключает/включает их доступ.

## Клиентский путь
- Добавлена регистрация, вход, выход и восстановление пароля клиента.
- Личный кабинет показывает только заявки, созданные в момент авторизованной сессии этого клиента.
- Регистрация не обязательна: гостевой заказ сохраняется в CRM, если указаны имя и телефон или email.
- Центр заказов передаёт заявку в CRM, получает постоянный номер и очищает корзину только после успешного сохранения.

## Важные ограничения тестовой версии
- Настоящая база и вход заработают после создания отдельного тестового проекта Supabase и заполнения локального `.env`.
- Реальную загрузку прикреплённых файлов в приватное хранилище пока не подключали: сейчас записываются только метаданные выбранных файлов.
- Гостевые заявки не связываются с аккаунтом задним числом.
- Не добавлены уведомления по email/SMS и защита публичной формы от массового спама; перед production это отдельные обязательные этапы.
- Эта копия не привязана и не должна публиковаться поверх `spiffy-kheer-42015a`.
