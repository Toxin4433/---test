НОВАЯ РЕАЛЬНОСТЬ — версия 2.0 (интерфейс кабинета менеджера)

ФАЙЛЫ
- index.html — главная страница
- catalog.html — каталог продукции
- configurator.html — интерактивный предварительный конструктор ПЭТ-упаковки
- business-center.html — центр заказов: общая корзина, запрос образцов и подготовка черновика заявки
- manager.html — демонстрационный кабинет менеджера: обзор, список обращений, фильтры, карточка заявки, статусы, заметки и выгрузка CSV
- manager.js / manager.css — логика и оформление кабинета менеджера

- kvass.html — отдельная презентация напитков «Русский Квас» и термокеги
- styles.css — оформление и анимации
- main.js — интерактивность, каталог и чат
- assets/ — визуализации продукции и фирменная эмблема brand-emblem.svg
- netlify/functions/chat.mjs — защищённый серверный обработчик ИИ-чата
- netlify.toml — настройки публикации на Netlify

КАК ОТКРЫТЬ ЛОКАЛЬНО
1. Откройте папку проекта в Visual Studio Code.
2. Для просмотра статических страниц запустите index.html через Live Server.
3. Каталог, фильтры, меню, презентация «Русский Квас» и локальные справочные ответы чата будут работать.
4. Полный ИИ-чат через Live Server не работает: для него нужен Netlify Functions.

КАК ПОДКЛЮЧИТЬ ИИ НА NETLIFY
1. Нужен аккаунт OpenAI API на platform.openai.com и активный способ оплаты API. Подписка ChatGPT сама по себе не является API-ключом и не оплачивает API-запросы.
2. Не вставляйте API-ключ в index.html, main.js или другие публичные файлы сайта.
3. В Netlify откройте свой проект → Project configuration (или Site configuration) → Environment variables.
4. Добавьте переменную OPENAI_API_KEY со значением вашего API-ключа. Секрет должен быть доступен для Functions.
5. При желании добавьте OPENAI_MODEL со значением модели, доступной вашему API-проекту. По умолчанию функция использует gpt-5.5.
6. Сохраните переменные и выполните новое развёртывание сайта.
7. Важно: для публикации серверной функции используйте Git-подключение или Netlify CLI. Обычная загрузка одной папки через Netlify Drop может опубликовать только статические страницы без функции ИИ.

ПУБЛИКАЦИЯ ЧЕРЕЗ NETLIFY CLI (если сайт уже создан в Netlify)
1. Установите Node.js LTS, если он ещё не установлен.
2. Откройте терминал VS Code в папке проекта.
3. Выполните: npm install -g netlify-cli
4. Выполните: netlify login
5. Выполните: netlify link и выберите созданный ранее сайт из списка.
6. Выполните: netlify deploy --prod
После публикации Netlify должен развернуть и страницы, и функцию из netlify/functions. Если появится запрос на подтверждение папки публикации, укажите текущую папку проекта (в netlify.toml уже задано publish = ".").

ЛОКАЛЬНЫЙ ЗАПУСК С ФУНКЦИЯМИ (для тех, кто готов установить Node.js и Netlify CLI)
1. Установите Node.js LTS.
2. В терминале VS Code выполните: npm install -g netlify-cli
3. Войдите в Netlify: netlify login
4. Перейдите в папку проекта и выполните: netlify dev
5. Для локального ИИ задайте OPENAI_API_KEY в переменных окружения терминала/локальной среды. Не отправляйте ключ в чат и не добавляйте его в файлы проекта.

ВАЖНО
- ИИ-чат не хранит переписку на этом сайте. История последних сообщений передаётся функции только для формирования ответа; запрос к Responses API отправляется с store:false.
- Ограничения длины сообщений и ответа уже заданы, но для публичного запуска дополнительно настройте лимиты расходов и защиту от злоупотреблений в панели API/хостинга.
- Контактная форма пока демонстрационная и НЕ отправляет заявки. Перед публикацией для клиентов нужно настроить реальную доставку заявок и добавить утверждённую политику конфиденциальности.
- Все продуктовые изображения являются визуализациями, а не фотографиями реальных серийных изделий. Перед публикацией их желательно заменить или дополнить фотографиями ассортимента компании.
- Цены, размеры, масса, тип горловины, характеристики сырья, наличие и сроки поставки не выдумываются и подтверждаются менеджером.


РАЗДЕЛ «РУССКИЙ КВАС»
- Добавлена отдельная страница kvass.html с ассортиментом: хлебный фильтрованный пастеризованный квас, квас живого брожения, лимонад «Саянъ», морс «Клюква» и «РусКола».
- Форматы упаковки приведены по открытой линейке russkvas.ru: ПЭТ 1,5 л (6 шт.), ПЭТ-кега 30 л; для части линейки — термокега 20 л. Текущую доступность конкретных SKU должен подтвердить менеджер ООО «Новая Реальность».
- В описании термокеги приведены конструкция, комплектность и условие хранения до 20 суток при температуре не выше +12 °C для закрытой ёмкости. Сверяйте сроки и условия с маркировкой конкретной партии.
- Контакты ООО «Торговый Дом „Русский Квас“» с сайта-источника не перенесены в контакты ООО «Новая Реальность». Награды и медицинские/оздоровительные утверждения не использованы.
- Фотографии напитков на исходной странице не удалось загрузить в проект; карточки пока используют имеющуюся визуализацию ПЭТ-бутылки с разными презентационными цветовыми решениями. Замените их на реальные фотографии согласованных SKU перед публичной рекламой.


НОВАЯ ВЕРСИЯ: ВИРТУАЛЬНАЯ ЭКСКУРСИЯ

В проект добавлена отдельная страница tour.html. Откройте её через пункт «Экскурсия» в верхнем меню или напрямую по адресу tour.html.

Внутри доступны два интерактивных маршрута:
1. «ПЭТ и полимеры» — 4 ознакомительных этапа: сырьё, подготовка материала, формование, контроль и готовая продукция.
2. «Напитки» — 5 этапов: подготовка компонентов, брожение, купажирование, проверка качества, розлив и упаковка.

Этапы можно выбирать кнопками на шкале либо проходить по порядку кнопками «Назад» и «Следующий этап». Иллюстрации являются схемами типовых технологических процессов, а не фотографиями цеха или технологической картой ООО «Новая Реальность». Для точных операций, оборудования и режимов требуется подтверждение производства.

Для локального просмотра запустите index.html или tour.html через Live Server в VS Code.

ОБНОВЛЕНИЕ 1.8 — ИНТЕРАКТИВНАЯ 3D-МОДЕЛЬ

На странице configurator.html добавлен интерактивный просмотр модели упаковки.
Для 3D используется Three.js версии 0.170.0, загружаемый с jsDelivr CDN.
Поэтому для отображения 3D-модели необходим интернет и поддержка WebGL в браузере.
Если библиотека не загрузится или WebGL недоступен, останется прежний SVG-эскиз.

Управление: перетаскивание мышью или пальцем вращает модель; колесо мыши меняет
масштаб. Также доступны ракурсы «Спереди», «3/4», «Сбоку», «Сзади», «Горловина»
и «Дно», ползунки поворота и масштаба, а также сброс вида.

3D-модель является демонстрационной визуализацией. Её геометрия и размеры не являются
производственным чертежом, подтверждённой пресс-формой или гарантией выпуска изделия.


ОБНОВЛЕНИЕ 1.9 — NR BUSINESS CENTER

Добавлена отдельная страница business-center.html — единый центр подготовки B2B-запросов.
В каталоге автоматически появились кнопки «Добавить в запрос» и «Запросить образец»
(для категорий полимерной продукции). В 3D-конструкторе добавлена кнопка переноса
текущей конфигурации в центр заказов.

Выбранные позиции сохраняются в localStorage текущего браузера и доступны при переходе
между страницами на одном домене. Пользователь может менять количество и удалять позиции.
В форме центра заказов доступны режимы: расчёт стоимости, запрос образца и индивидуальное
изготовление; контактные поля, комментарий и выбор до трёх файлов (до 15 МБ каждый).

ВАЖНО — ЧТО РАБОТАЕТ И ЧТО ПОКА НЕ ПОДКЛЮЧЕНО
- Центр формирует на устройстве текстовый файл-черновик с выбранными позициями и контактами.
- Контактные данные не отправляются в интернет и не сохраняются в браузере сайтом.
- Выбранные позиции сохраняются локально в браузере через localStorage.
- Выбранные чертежи/фото не загружаются на сервер; в черновик попадают только их имена.
  Сами файлы необходимо отдельно передать менеджеру.
- Реальная доставка заявки и файлов на почту/в CRM НЕ подключена. До интеграции нельзя
  обещать посетителю, что после нажатия кнопки заявка получена компанией.
- Цены, сроки, наличие, техническая реализуемость и возможность изготовления подтверждаются
  менеджером. Конфигурация из конструктора остаётся предварительным эскизом.

Для проверки: откройте catalog.html, добавьте несколько позиций в запрос, перейдите в
business-center.html, измените количество, выберите тип запроса и сформируйте тестовый
черновик с вымышленными данными. Для добавления конфигурации откройте configurator.html
и используйте кнопку «Добавить в центр заказов».


ОБНОВЛЕНИЕ 2.0 — NR MANAGER (ДЕМОНСТРАЦИОННЫЙ КАБИНЕТ)
- Добавлена отдельная страница manager.html. Она намеренно не включена в публичное меню сайта.
- В кабинете есть обзорные показатели, список заявок, фильтры по статусу и типу, поиск, карточка обращения, изменение статуса/приоритета, внутренняя заметка и экспорт текущего списка в CSV.

- Встроены три вымышленные демонстрационные заявки; телефоны и email в них не являются контактами реальных клиентов.

КРИТИЧЕСКОЕ ОГРАНИЧЕНИЕ БЕЗОПАСНОСТИ
- Кабинет менеджера на этой версии является ТОЛЬКО интерфейсным прототипом. В нём нет авторизации, серверной базы данных, разграничения ролей и синхронизации между устройствами.
- Страница manager.html может быть открыта по прямому URL любым посетителем, если сайт опубликован. Не используйте этот прототип для просмотра, хранения или обработки реальных персональных данных клиентов и не считайте ссылку или meta noindex защитой доступа.
- Импортированные TXT-черновики обрабатываются в памяти текущей вкладки и не передаются на сервер. При перезагрузке страницы импортированные записи и изменения статусов/заметок исчезают. CSV-экспорт сохраняется только после явного нажатия менеджером.
- Тестовые записи помечены как демо. Не звоните и не пишите на указанные в них фиктивные контакты.

ЧТО НУЖНО ДЛЯ РЕАЛЬНОГО ЗАПУСКА КАБИНЕТА
1. Подключить серверное сохранение заявок и файлов (например, Supabase или другую БД/CRM).
2. Настроить настоящую авторизацию менеджеров и администраторов, роли и права доступа.
3. Закрыть API проверкой сессии и серверными правилами доступа; не полагаться на скрытие HTML-страницы.
4. Настроить безопасную загрузку файлов, ограничения форматов/размеров, хранение и сроки удаления.
5. Подключить форму business-center.html к серверному обработчику. Сейчас публичный сайт по-прежнему создаёт локальный TXT-черновик и не отправляет реальную заявку.
6. Настроить журнал действий менеджеров и резервное копирование.

КАК ПОСМОТРЕТЬ ДЕМО-КАБИНЕТ
- Запустите проект через Live Server и откройте manager.html.
- Нажмите «Импортировать черновик» и выберите TXT-файл, ранее скачанный из Центра заказов.

- Не загружайте реальные данные клиентов в публично опубликованный прототип.
